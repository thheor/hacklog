## Bandit Level 3 -> 4

Level Goal

The password for the next level is stored in a hidden file in the inhere directory.
Commands you may need to solve this level

`ls, cd, cat, file, du, find`

## Solutions

```bash
ls -als # to list the files and directory on current working directory

cd inhere # move to inhere directory
cat ...Hiding-From-You # concatenate file
```
